## Quick Start — Native Desktop App

### 1. Setup

```bash
# Clone / navigate to directory
cd DPP_Agent

# Use the v2 virtual environment
source .venv/bin/activate

# Install dependencies (first time only)
python -m pip install -r requirements.txt

# Copy and fill in your Groq API key
cp .env.example .env
nano .env   # Set GROQ_API_KEY
```

### 2. Launch the GUI

```bash
./run.sh
# or, after activation:
python main.py
```

The native window provides topic, difficulty, problem type, count, research
depth, hints, explanations, cloud/local model preference, answer visibility,
and Markdown / JSON / plain-text export controls. Generation runs in a worker
thread so the window remains responsive during research and model calls.

### 3. Run — CLI Mode (optional)

```bash
# 10 hard MCQs on UPSC Polity via Groq cloud
./run.sh --topic "UPSC Polity" --difficulty hard --type mcq --count 10 --export all

# 5 easy fill-in-blank on Chemical Bonding using local Ollama only
./run.sh --topic "Chemical Bonding" --difficulty easy --type fill_blank --count 5 --no-cloud

# Short answers on Data Structures, show answers in terminal
./run.sh --topic "Data Structures" --difficulty medium --type short_answer --count 8 --show-answers
```

## CLI Reference

```
python main.py [OPTIONS]

Options:
  --topic TEXT            Topic (e.g. "Chemical Bonding", "UPSC Geography")
  --difficulty            easy | medium | hard          [default: medium]
  --type                  mcq | short_answer | long_answer | fill_blank | true_false
                                                        [default: mcq]
  --count INT             Number of problems (1–30)     [default: 5]
  --depth                 light | medium | deep          [default: medium]
  --export                json | markdown | text | all | none [default: markdown]
  --show-answers          Show answers in terminal output
  --no-hints              Omit per-problem hints
  --no-explanations       Omit per-problem explanations
  --no-cloud              Force local Ollama (ignore Groq API key)
  --groq-key TEXT         Override GROQ_API_KEY at runtime
```

## Environment Variables (`.env`)

| Variable | Default | Description |
|---|---|---|
| `GROQ_API_KEY` | *(required for cloud)* | Get from [console.groq.com](https://console.groq.com) |
| `GROQ_MODEL` | `llama-3.3-70b-versatile` | Any Groq-supported model |
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollama server URL |
| `OLLAMA_MODEL` | `qwen3:1.7b` | Must be pre-pulled via `ollama pull qwen3:1.7b` |
| `WIKI_LANG` | `en` | Wikipedia language code |
| `OUTPUT_DIR` | `./output` | Where exports are saved |

The native GUI uses PySide6. Install dependencies with the `v2/.venv` Python:

```bash
./.venv/bin/python -m pip install -r requirements.txt
```
